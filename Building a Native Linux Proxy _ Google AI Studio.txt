networking stack as the gold standard, we have to discard the entire
design paradigm used by cross-platform clients (NekoBox, Hiddify,
v2rayN, etc.).

Most existing clients make three fatal mistakes:

 1.

    schema (coupling the UI directly to core updates).

 2.

    They treat health testing as a crude "blast Google/Cloudflare with
    HTTP 204s" (which flags nodes to DPI and gives meaningless latency
    numbers).

 3.

    They render giant lists using basic unvirtualized UI widgets without
    an indexed data layer, choking the main loop on any list larger than
    500 nodes.

Below is an engineering blueprint for how this client should be
architected from the kernel up.

    1. Core Decoupling: Bleeding-Edge Compatibility Without Breakage

Existing GUIs break whenever Xray or sing-box adjusts their JSON schemas
or deprecates fields (e.g., changes in VLESS flow types, REALITY
configurations, or mux settings).


      The Canonical Intermediate Representation (IR)

The application must *never*store or manipulate raw Xray or sing-box
JSON. Instead, all incoming subscriptions (VLESS, VMess, Trojan,
Shadowsocks, TUIC, Hysteria2, WireGuard) are parsed into a strictly
typed, immutable *Canonical Intermediate Representation (IR)*:

      Dynamic Adapter Pipeline & Capability Discovery

The bridge between the Canonical IR and the proxy binary is an isolated
*Core Adapter*:

 1.

    *Schema Generation as a Pure Function*: fn compile(ir:
    &OutboundNode, routing: &RoutingRules) -> CoreConfigString. The core
    configuration is an ephemeral artifact generated in-memory (or piped
    via stdin/Unix socket) right before invocation.

 2.

    *Capability Introspection*: On startup or core update, the daemon
    invokes the core binary with diagnostic flags (e.g., xray -versionor
    test configurations) to introspect supported protocols and flags. If
    a flag like xhttpis absent on an older binary, or deprecated on a
    newer one, the adapter selects the fallback dialect dynamically.

 3.

    *Dry-Run Validation Sandbox*: Before applying any configuration to
    the running supervisor, the adapter spawns an isolated dry-run
    process (xray -test -config stdin). If the core rejects the
    generated config, the application isolates the error, flags the
    incompatible node in the UI, and never breaks the primary engine.

 4.

    *Lifecycle via pidfd*: Never track PIDs via shell scripts or raw
    integer checks. Use Linux pidfd_open(2)and epoll(7)to supervise core
    lifecycles, capturing standard error streams into structured
    circular memory buffers for real-time telemetry.

    risking mass IP blacklisting.

  *

    *CDN Edge Misrepresentation*: Cloudflare edge anycast responds at
    the nearest point of presence to the proxy, which tells you nothing
    about whether the proxy can reach broader transit routes.

  *

    *Single-Packet Fallacy*: An HTTP 204 confirms a single TCP/TLS
    handshake succeeded at second

    4. Native Linux Networking Integration

Cross-platform clients run messy root processes, shell out to /usr/bin/
ipcommands, leave broken iptablesrules behind on crash, or overwrite /
etc/resolv.conf. A Linux-first client uses dedicated kernel interfaces.


      A. TPROXY over TUN (Zero-Copy Kernel Redirection)

Most clients default to TUN devices. TUN requires:

 1.

    Packet encapsulation in userspace.

 2.

    Context switches (read()/ write()on /dev/net/tun).

 3.

    Running a full userspace TCP/IP stack (gVisor / lwIP) inside the
    client before handing traffic to the proxy core.

*The Linux Native Way: TPROXY + nftables*

  *

    Use Linux TPROXY(IP_TRANSPARENT). The kernel redirects TCP and UDP
    packets directly to the proxy core's listening socket without
    userspace packet re-assembly.

  *

    Configure packet routing using libnftables(via the native C/Rust
    API), not by invoking external iptablesbinary subprocesses:

pub fn read_kernel_socket_stats(fd: std::os::unix::io::RawFd) -> std::io::Result<TcpStats> {
    let mut info: libc::tcp_info = unsafe { std::mem::zeroed() };
    let mut len = std::mem::size_of::<libc::tcp_info>() as libc::socklen_t;

        libc::getsockopt(

            libc::SOL_TCP,
            libc::TCP_INFO,
            &mut info as *mut _ as *mut libc::c_void,
            &mut len,

            rtt_var_us: info.tcpi_rttvar,
            lost_packets: info.tcpi_lost,
            retransmits: info.tcpi_retrans,

        Err(std::io::Error::last_os_error())
    }

The Canonical Intermediate Representation (IR) is the central nervous
system of this entire project.

If this layer is poorly designed:

  *

    Subscriptions with 50,000 nodes will chew through gigabytes of memory.

  *

    Duplicate nodes with different emoji labels across 20 subscriptions
    will trigger redundant health checks.

  *

    Every minor Xray or sing-box schema update will force a rewrite of
    your UI models.

The Canonical IR must be *protocol-pure*: it models the mathematical and
networking realityof the proxy connection, completely divorced from how
Xray, sing-box, or Mihomo format their JSON files.

------------------------------------------------------------------------


      Canonical IR Design Principles

 1.

    *Separation of Identity from Topology*: A node's name, subscription
    source, and latencyare metadata. A node's server, port, protocol,
    transport, and keysare its *functional identity*.

 2.

    *Deterministic Functional Hashing*: Two nodes with different names
    (e.g., 🇩🇪 Frankfurt 01vs [VIP] Germany-HighSpeed) that point to the
    exact same server and credentials must produce the exact same *32-
    byte SHA-256 Canonical Hash*. This gives us instant

            
    |O(1)O(1)O(1)

    |
          

    deduplication across subscriptions.

 3.

    *Cache-Line Alignment*: The core data structures must avoid
    scattered heap allocations. Strings are bounded, small keys use
    fixed arrays or compact interned buffers, and integers use the
    smallest viable bitwidth.

      4. Deterministic Canonical Hashing (Deduplication)

To calculate whether two nodes are physically identical regardless of
their name or origin, we serialize *only the functional networking
fields*into a canonical byte sequence and run SHA-256:

code Rust

content_copy

expand_less

|impl CanonicalNode {
    /// Constructs a new node and automatically computes its deterministic identity hash.
    pub fn new(
        meta: NodeMetadata,
        endpoint: EndpointTarget,
        protocol: ProtocolSpec,
        transport: TransportSpec,
        security: SecuritySpec,
        mux: Option<MuxSpec>,
    ) -> Self {
        // Functional identity tuple
        let identity_payload = (
            &endpoint,
            &protocol,
            &transport,
            &security,
            &mux,
        );

        // Serialize using canonical deterministic bincode
        let serialized_bytes = bincode::serialize(&identity_payload)
            .expect("Fatal: Failed to serialize functional identity");

        let mut hasher = Sha256::new();
        hasher.update(&serialized_bytes);
        let hash: CanonicalHash = hasher.finalize().into();

        Self {
            hash,
            meta,
            endpoint,
            protocol,
            transport,
            security,
            mux,
        }
    }
}

|use crate::adapter::{CoreAdapter, CoreCapabilities};
use crate::*;
use anyhow::{bail, Result};
use serde_json::{json, Value};
use std::path::Path;

pub struct SingBoxAdapter;

impl CoreAdapter for SingBoxAdapter {
    fn name(&self) -> &'static str {
        "sing-box"
    }

    fn probe_capabilities(&self, binary_path: &Path) -> Result<CoreCapabilities> {
        let output = std::process::Command::new(binary_path)
            .arg("version")
            .output()?;

        let stdout = String::from_utf8_lossy(&output.stdout);
        
        // Capability matrix derived from version string
        Ok(CoreCapabilities {
            core_name: "sing-box".into(),
            version: stdout.to_string(),
            supports_vless_reality: true,
            supports_xhttp: stdout.contains("1.10") || stdout.contains("1.11"),
            supports_hysteria2: true,
            supports_tuic: true,
            supports_multipath: true,
        })
    }

    fn compile_outbound(&self, node: &CanonicalNode, caps: &CoreCapabilities) -> Result<Value> {
        let mut outbound = json!({
            "tag": format!("proxy-{}", hex::encode(&node.hash[0..4])),
        });

        // 1. Resolve Endpoint
        match &node.endpoint {
            EndpointTarget::Ip(addr) => {
                outbound["server"] = json!(addr.ip().to_string());
                outbound["server_port"] = json!(addr.port());
            }
            EndpointTarget::Domain { host, port } => {
                outbound["server"] = json!(host.as_ref());
                outbound["server_port"] = json!(port);
            }
        }

        // 2. Map Protocol
        match &node.protocol {
            ProtocolSpec::Vless(vless) => {
                outbound["type"] = json!("vless");
                outbound["uuid"] = json!(vless.uuid.to_string());
                if let Some(flow) = &vless.flow {
                    outbound["flow"] = match flow {
                        VlessFlow::XtlsRprxVision => json!("xtls-rprx-vision"),
                        VlessFlow::XtlsRprxVisionUdp443 => json!("xtls-rprx-vision-udp443"),
                    };
                }
            }
            ProtocolSpec::Hysteria2(hy2) => {
                if !caps.supports_hysteria2 {
                    bail!("Installed sing-box binary does not support Hysteria2");
                }
                outbound["type"] = json!("hysteria2");
                outbound["password"] = json!(hy2.password.as_ref());
                if let Some(up) = hy2.up_mbps { outbound["up_mbps"] = json!(up); }
                if let Some(down) = hy2.down_mbps { outbound["down_mbps"] = json!(down); }
                if let Some(obfs) = &hy2.obfs {
                    outbound["obfs"] = json!({
                        "type": obfs.obfs_type.as_ref(),
                        "password": obfs.password.as_ref()
                    });
                }
            }
            ProtocolSpec::Trojan(trojan) => {
                outbound["type"] = json!("trojan");
                outbound["password"] = json!(trojan.password.as_ref());
            }
            ProtocolSpec::Shadowsocks(ss) => {
                outbound["type"] = json!("shadowsocks");
                outbound["method"] = json!(format!("{:?}", ss.method).to_lowercase());
                outbound["password"] = json!(ss.password.as_ref());
            }
            _ => bail!("Protocol compilation not yet implemented for target"),
        }

        // 3. Map Transport (V2Ray transport layer)
        match &node.transport {
            TransportSpec::Tcp => {}
            TransportSpec::WebSocket(ws) => {
                outbound["transport"] = json!({
                    "type": "ws",
                    "path": ws.path.as_ref(),
                    "headers": ws.host.as_ref().map(|h| json!({"Host": h.as_ref()})),
                    "max_early_data": ws.max_early_data
                });
            }
            TransportSpec::Grpc(grpc) => {
                outbound["transport"] = json!({
                    "type": "grpc",
                    "service_name": grpc.service_name.as_ref()
                });
            }
            TransportSpec::XHttp(xhttp) => {
                if !caps.supports_xhttp {
                    bail!("XHTTP transport requested, but core does not support it. Downgrade or fallback required.");
                }
                outbound["transport"] = json!({
                    "type": "xhttp",
                    "mode": match xhttp.mode {
                        XHttpMode::StreamOne => "stream-one",
                        XHttpMode::StreamUp => "stream-up",
                        XHttpMode::PacketUp => "packet-up",
                    },
                    "path": xhttp.path.as_ref(),
                    "host": xhttp.host.as_ref().map(|h| h.as_ref())
                });
            }
            _ => {}
        }

        // 4. Map Security / TLS Layer
        match &node.security {
            SecuritySpec::None => {}
            SecuritySpec::Tls(tls) => {
                outbound["tls"] = json!({
                    "enabled": true,
                    "server_name": tls.server_name.as_ref(),
                    "insecure": tls.allow_insecure,
                    "alpn": tls.alpn.iter().map(|a| a.as_ref()).collect::<Vec<&str>>(),
                    "utls": {
                        "enabled": tls.fingerprint != UtlsFingerprint::None,
                        "fingerprint": format!("{:?}", tls.fingerprint).to_lowercase()
                    }
                });
            }
            SecuritySpec::Reality(reality) => {
                outbound["tls"] = json!({
                    "enabled": true,
                    "server_name": reality.server_name.as_ref(),
                    "reality": {
                        "enabled": true,
                        "public_key": reality.public_key.as_ref(),
                        "short_id": reality.short_id.as_ref()
                    },
                    "utls": {
                        "enabled": true,
                        "fingerprint": format!("{:?}", reality.fingerprint).to_lowercase()
                    }
                });
            }
        }

        Ok(outbound)
    }

    fn validate_config(&self, binary_path: &Path, full_config_json: &str) -> Result<()> {
        let mut child = std::process::Command::new(binary_path)
            .args(["check", "-c", "stdin"])
            .stdin(std::process::Stdio::piped())
            .stderr(std::process::Stdio::piped())
            .spawn()?;

        use std::io::Write;
        if let Some(mut stdin) = child.stdin.take() {
            stdin.write_all(full_config_json.as_bytes())?;
        }

        let output = child.wait_with_output()?;
        if !output.status.success() {
            let stderr_err = String::from_utf8_lossy(&output.stderr);
            bail!("Sing-box configuration check failed: {}", stderr_err);
        }

        Ok(())
    }
}

|use base64::engine::general_purpose::{STANDARD, URL_SAFE};
use base64::Engine;

pub fn normalize_and_decode_base64(raw: &[u8]) -> Option<Vec<u8>> {
    let trimmed = raw.trim_ascii();
    if trimmed.is_empty() {
        return None;
    }

    // Try standard base64 first
    if let Ok(decoded) = STANDARD.decode(trimmed) {
        return Some(decoded);
    }

    // Try URL-safe base64
    if let Ok(decoded) = URL_SAFE.decode(trimmed) {
        return Some(decoded);
    }

    // Fix missing padding if omitted
    let mut padded = trimmed.to_vec();
    while padded.len() % 4 != 0 {
        padded.push(b'=');
    }

    STANDARD
        .decode(&padded)
        .or_else(|_| URL_SAFE.decode(&padded))
        .ok()
}

pub enum DetectedFormat {
    Base64Bundle,
    PlaintextLines,
    JsonAst,
}

pub fn detect_format(bytes: &[u8]) -> DetectedFormat {
    let trimmed = bytes.trim_ascii_start();
    if trimmed.starts_with(b"{") || trimmed.starts_with(b"[") {
        DetectedFormat::JsonAst
    } else if trimmed.starts_with(b"vless://")
        || trimmed.starts_with(b"vmess://")
        || trimmed.starts_with(b"trojan://")
        || trimmed.starts_with(b"ss://")
        || trimmed.starts_with(b"hysteria2://")
        || trimmed.starts_with(b"hy2://")
    {
        DetectedFormat::PlaintextLines
    } else {
        DetectedFormat::Base64Bundle
    }
}

pub fn parse_vless(raw: &str, sub_id: SubId) -> Result<CanonicalNode, ParseError> {

            path: query.get("path").cloned().unwrap_or_else(|| "/".into()).into(),
            host: query.get("host").cloned().map(|h| h.into()),

            early_data_header: None,
        }),

        }),
        "xhttp" => TransportSpec::XHttp(XHttpConfig {
            mode: match query.get("mode").map(|s| s.as_str()) {
                Some("packet-up") => XHttpMode::PacketUp,
                Some("stream-up") => XHttpMode::StreamUp,
                _ => XHttpMode::StreamOne,
            },
            path: query.get("path").cloned().unwrap_or_else(|| "/".into()).into(),
            host: query.get("host").cloned().map(|h| h.into()),
        }),

            public_key: query.get("pbk").cloned().ok_or(ParseError::MissingField("pbk"))?.into(),
            short_id: query.get("sid").cloned().unwrap_or_default().into(),
            spider_x: query.get("spx").cloned().map(|s| s.into()),
            fingerprint: parse_utls_fp(query.get("fp").map(|s| s.as_str())),
        }),
        "tls" => SecuritySpec::Tls(StandardTlsConfig {
            server_name: query.get("sni").cloned().unwrap_or_default().into(),
            alpn: query.get("alpn").map(|a| a.split(',').map(|s| s.into()).collect()).unwrap_or_default(),

            allow_insecure: query.get("allowInsecure").map(|v| v == "1" || v == "true").unwrap_or(false),
        }),
        _ => SecuritySpec::None,
    };

        Some("xtls-rprx-vision") => Some(VlessFlow::XtlsRprxVision),
        Some("xtls-rprx-vision-udp443") => Some(VlessFlow::XtlsRprxVisionUdp443),

        endpoint,

        transport,
        security,
        None,

|/// Scans label bytes for Regional Indicator Symbols (Emoji flags) or bracket tags.
/// Converts Emoji Flag '🇩🇪' directly to ISO byte code *b"DE" without string allocations.
pub fn extract_country_code(label: &str) -> [u8; 2] {
    let bytes = label.as_bytes();

    // 1. Scan for Unicode Regional Indicator pairs (Emoji Flags)
    // Each Regional Indicator Symbol is 4 bytes in UTF-8: 0xF0 0x9F 0x87 [0xA6..0xBF]
    let mut i = 0;
    while i + 8 <= bytes.len() {
        if bytes[i] == 0xF0 && bytes[i + 1] == 0x9F && bytes[i + 2] == 0x87
            && bytes[i + 4] == 0xF0 && bytes[i + 5] == 0x9F && bytes[i + 6] == 0x87
        {
            let char1 = bytes[i + 3];
            let char2 = bytes[i + 7];

            // 0xA6 maps to 'A', 0xBF maps to 'Z'
            if (0xA6..=0xBF).contains(&char1) && (0xA6..=0xBF).contains(&char2) {
                let ascii_first = char1 - 0xA6 + b'A';
                let ascii_second = char2 - 0xA6 + b'A';
                return [ascii_first, ascii_second];
            }
        }
        i += 1;
    }

    // 2. Scan for common bracket patterns: "[US]", "(HK)", "-JP-"
    if let Some(pos) = label.find(|c| c == '[' || c == '(' || c == '-') {
        let candidate = &label[pos + 1..];
        if candidate.len() >= 2 {
            let potential_code = &candidate.as_bytes()[0..2];
            if potential_code[0].is_ascii_uppercase() && potential_code[1].is_ascii_uppercase() {
                return [potential_code[0], potential_code[1]];
            }
        }
    }

    // Default: Unknown country
    *b"UN"
}

|pub mod format;

use format::{detect_format, normalize_and_decode_base64, DetectedFormat};
use ir::{CanonicalHash, CanonicalNode, SubId};
use report::{IngestionReport, ParseError, ParseFailure};
use std::collections::HashSet;

pub struct SubscriptionEngine;

impl SubscriptionEngine {
    /// Ingests a raw subscription buffer and transforms it into deduplicated Canonical Nodes.
    pub fn ingest(
        raw_payload: &[u8],
        sub_id: SubId,
        existing_hashes: &HashSet<CanonicalHash>,
    ) -> IngestionReport {
        let mut report = IngestionReport {
            total_lines_scanned: 0,
            successful_nodes: Vec::with_capacity(1024),
            duplicates_omitted: 0,
            failed_entries: Vec::new(),
        };

        // 1. Unpack container
        let content_bytes = match detect_format(raw_payload) {
            DetectedFormat::Base64Bundle => {
                normalize_and_decode_base64(raw_payload).unwrap_or_else(|| raw_payload.to_vec())
            }
            _ => raw_payload.to_vec(),
        };

        let content_str = String::from_utf8_lossy(&content_bytes);

        // 2. Iterate lines (Split on \n or \r\n)
        for (idx, raw_line) in content_str.lines().enumerate() {
            let line = raw_line.trim();
            if line.is_empty() {
                continue;
            }

            report.total_lines_scanned += 1;

            let parse_result = if line.starts_with("vless://") {
                vless::parse_vless(line, sub_id)
            } else if line.starts_with("vmess://") {
                vmess::parse_vmess(line, sub_id)
            } else if line.starts_with("hysteria2://") || line.starts_with("hy2://") {
                hysteria2::parse_hysteria2(line, sub_id)
            } else {
                Err(ParseError::InvalidScheme(
                    line.chars().take(15).collect::<String>(),
                ))
            };

            match parse_result {
                Ok(node) => {
                    // Check against database hashes + active batch
                    if existing_hashes.contains(&node.hash)
                        || report.successful_nodes.iter().any(|n| n.hash == node.hash)
                    {
                        report.duplicates_omitted += 1;
                    } else {
                        report.successful_nodes.push(node);
                    }
                }
                Err(err) => {
                    report.failed_entries.push(ParseFailure {
                        line_number: idx + 1,
                        raw_snippet: line.chars().take(80).collect(),
                        reason: err,
                    });
                }
            }
        }

        report
    }
}

|use anyhow::Result;
use ir::{CanonicalHash, CanonicalNode};
use rusqlite::{params, Connection, Transaction};
use std::collections::HashSet;

pub struct NodeRepository;

impl NodeRepository {
    /// Ingests a slice of nodes in a single transaction, skipping duplicates.
    pub fn bulk_insert_nodes(
        tx: &Transaction,
        sub_id: u16,
        nodes: &[CanonicalNode],
    ) -> Result<usize> {
        let mut inserted_count = 0;

        let mut node_stmt = tx.prepare_cached(
            r#"
            INSERT INTO nodes (sub_id, hash, name, country_code, raw_payload)
            VALUES (?1, ?2, ?3, ?4, ?5)
            ON CONFLICT(hash) DO NOTHING
            RETURNING id;
            "#,
        )?;

        let mut diag_stmt = tx.prepare_cached(
            r#"
            INSERT INTO node_diagnostics (node_id, last_tested, latency_ms, health_score)
            VALUES (?1, 0, 65535, 0);
            "#,
        )?;

        for node in nodes {
            let country_str = std::str::from_utf8(&node.meta.country_code).unwrap_or("UN");
            let raw_bincode = bincode::serialize(node)?;

            // Execute insert
            let mut rows = node_stmt.query(params![
                sub_id,
                &node.hash[..],
                node.meta.label.as_ref(),
                country_str,
                raw_bincode
            ])?;

            if let Some(row) = rows.next()? {
                let node_id: u32 = row.get(0)?;
                diag_stmt.execute(params![node_id])?;
                inserted_count += 1;
            }
        }

        Ok(inserted_count)
    }

    /// Fetches all 32-byte hashes to facilitate O(1) in-memory deduplication before parsing
    pub fn load_all_hashes(conn: &Connection) -> Result<HashSet<CanonicalHash>> {
        let mut stmt = conn.prepare("SELECT hash FROM nodes")?;
        let rows = stmt.query_map([], |row| {
            let slice: Vec<u8> = row.get(0)?;
            let mut hash = [0u8; 32];
            hash.copy_from_slice(&slice);
            Ok(hash)
        })?;

        let mut set = HashSet::new();
        for hash in rows {
            set.insert(hash?);
        }
        Ok(set)
    }
}

|use ahash::AHashMap;
use anyhow::Result;
use rusqlite::Connection;
use std::sync::Arc;

pub const UNTESTED_LATENCY: u16 = 65535;

/// Contiguous, cache-line aligned Structure-of-Arrays
#[derive(Default, Clone)]
pub struct DenseNodeStore {
    pub node_ids: Vec<u32>,
    pub sub_ids: Vec<u16>,
    pub country_codes: Vec<[u8; 2]>,
    pub latencies_ms: Vec<u16>,      // 0xFFFF represents Untested/Offline
    pub health_scores: Vec<u8>,      // 0..100 composite stability
    pub names: Vec<Box<str>>,

    /// Fast reverse lookup: NodeId -> dense index
    id_to_index: AHashMap<u32, usize>,
}

impl DenseNodeStore {
    pub fn with_capacity(capacity: usize) -> Self {
        Self {
            node_ids: Vec::with_capacity(capacity),
            sub_ids: Vec::with_capacity(capacity),
            country_codes: Vec::with_capacity(capacity),
            latencies_ms: Vec::with_capacity(capacity),
            health_scores: Vec::with_capacity(capacity),
            names: Vec::with_capacity(capacity),
            id_to_index: AHashMap::with_capacity(capacity),
        }
    }

    /// Hydrates the flat SOA store directly from SQLite in a single pass.
    pub fn hydrate_from_db(conn: &Connection) -> Result<Self> {
        let mut stmt = conn.prepare(
            r#"
            SELECT 
                n.id, n.sub_id, n.country_code, n.name,
                COALESCE(d.latency_ms, 65535),
                COALESCE(d.health_score, 0)
            FROM nodes n
            LEFT JOIN node_diagnostics d ON n.id = d.node_id
            ORDER BY n.id ASC
            "#,
        )?;

        let mut store = DenseNodeStore::with_capacity(50_000);

        let mut rows = stmt.query([])?;
        let mut idx = 0;

        while let Some(row) = rows.next()? {
            let id: u32 = row.get(0)?;
            let sub_id: u16 = row.get(1)?;
            let country_str: String = row.get(2)?;
            let name: String = row.get(3)?;
            let latency: u16 = row.get(4)?;
            let health: u8 = row.get(5)?;

            let country_bytes = country_str.as_bytes();
            let country: [u8; 2] = if country_bytes.len() >= 2 {
                [country_bytes[0], country_bytes[1]]
            } else {
                *b"UN"
            };

            store.node_ids.push(id);
            store.sub_ids.push(sub_id);
            store.country_codes.push(country);
            store.names.push(name.into_boxed_str());
            store.latencies_ms.push(latency);
            store.health_scores.push(health);

            store.id_to_index.insert(id, idx);
            idx += 1;
        }

        Ok(store)
    }

    #[inline(always)]
    pub fn len(&self) -> usize {
        self.node_ids.len()
    }

    /// Updates diagnostic metrics in-place without heap allocations.
    pub fn update_metrics(&mut self, node_id: u32, latency_ms: u16, health_score: u8) {
        if let Some(&index) = self.id_to_index.get(&node_id) {
            self.latencies_ms[index] = latency_ms;
            self.health_scores[index] = health_score;
        }
    }
}

|use crate::soa_store::{DenseNodeStore, UNTESTED_LATENCY};
use std::cmp::Ordering;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum SortCriteria {
    LatencyAsc,
    LatencyDesc,
    CountryAsc,
    NameAsc,
    HealthScoreDesc,
}

pub struct QueryEngine;

impl QueryEngine {
    /// Filters and sorts dense cache indices into a projected slice ready for Slint.
    pub fn query(
        store: &DenseNodeStore,
        search_term: &str,
        country_filter: Option<[u8; 2]>,
        sub_filter: Option<u16>,
        sort: SortCriteria,
    ) -> Vec<u32> {
        let total = store.len();
        let mut active_indices: Vec<u32> = Vec::with_capacity(total);
        let search_lower = search_term.to_lowercase();
        let has_search = !search_lower.is_empty();

        // 1. Vectorized Filter Pass
        for i in 0..total {
            // Subscription filter
            if let Some(target_sub) = sub_filter {
                if store.sub_ids[i] != target_sub {
                    continue;
                }
            }

            // Country code filter (2-byte direct integer comparison)
            if let Some(target_country) = country_filter {
                if store.country_codes[i] != target_country {
                    continue;
                }
            }

            // Substring search over name
            if has_search && !store.names[i].to_lowercase().contains(&search_lower) {
                continue;
            }

            active_indices.push(i as u32);
        }

        // 2. High-Speed Index Sort Pass
        match sort {
            SortCriteria::LatencyAsc => {
                active_indices.sort_unstable_by(|&a, &b| {
                    let lat_a = store.latencies_ms[a as usize];
                    let lat_b = store.latencies_ms[b as usize];

                    // Push untested/timeout nodes (0xFFFF) to the back
                    match (lat_a == UNTESTED_LATENCY, lat_b == UNTESTED_LATENCY) {
                        (true, true) => Ordering::Equal,
                        (true, false) => Ordering::Greater,
                        (false, true) => Ordering::Less,
                        (false, false) => lat_a.cmp(&lat_b),
                    }
                });
            }
            SortCriteria::CountryAsc => {
                active_indices.sort_unstable_by(|&a, &b| {
                    let c_a = store.country_codes[a as usize];
                    let c_b = store.country_codes[b as usize];
                    c_a.cmp(&c_b)
                });
            }
            SortCriteria::NameAsc => {
                active_indices.sort_unstable_by(|&a, &b| {
                    store.names[a as usize].cmp(&store.names[b as usize])
                });
            }
            SortCriteria::HealthScoreDesc => {
                active_indices.sort_unstable_by(|&a, &b| {
                    store.health_scores[b as usize].cmp(&store.health_scores[a as usize])
                });
            }
            _ => {}
        }

        active_indices
    }
}
